# Changelog

## 0.1.0-beta.5 (prepared, not released)

- Scoped mode and Folio rules to Lamplight boundaries while retaining inherited and nested modes.
- Preserved React menu keyboard focus across unrelated parent renders.
- Kept chapter navigation and anchor targets readable without JavaScript.
- Added checked release downloads and a manually gated GitHub Pages workflow.
- Updated development dependencies, clean-checkout privacy checks and platform-specific browser baselines.

- Corrected FocalCatch to follow Day paper and ink with a crisp source marker.
- Added rendered Roman-numeral chapter openers and overview pills to the component reference.
- Versioned preview styles by content so refreshed pages load current component and mode rules.

- Added Chapter rail, Chapter opener and Case overview components, with an opt-in scroll-tracking module.
- Aligned rail dots, connecting rules, subsection labels and chapter arguments, with measured header offsets and responsive/print handling.

- Added a compact pill size for segmented controls with an ink underline in Folio.
- Documented and demonstrated a persistent Night, Day and Folio appearance switcher.

## 0.1.0-beta.4 (prepared, not released)

- Clarified navigation between the examples, components and principles pages, with Get started on the landing page.
- Added AI starter guidance for working with the local beta files.

## 0.1.0-beta.3 (prepared, not released)

- Restored the compact Field notes landing and moved expanded Reading, Report and Dashboard compositions to a separate examples guide.
- Added example presets, a lean print view and an active example mode and surface indicator.

## 0.1.0-beta.2 (prepared, not released)

- Added Lead line and Thread patterns, including React bindings and HTML and React guidance.
- Expanded the showcase with reading, report and dashboard examples, plus component and principles reference pages.
- Preserved Panel grain and focal backgrounds in compositions, kept Thread geometry in print, and limited sticky Ledger headings to column headers.

## 0.1.0-beta.1 (prepared, not released)

- Prepared a free community beta as GitHub release files: core and React tarballs and a browser starter ZIP.
- Added Night and Day modes, Ledger and Folio surfaces, and experimental automatic Folio print styling.
- Prepared framework-neutral tokens and CSS, optional fonts and living light, structural React bindings and examples.
- Real Safari, manual assistive technology and physical monochrome print remain unobserved. See the [beta notes](docs/release/beta-release-notes.md).

No version has been published. These package names do not claim an npm namespace.
