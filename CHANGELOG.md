# Changelog

## 0.1.0-beta.3 (prepared, not released)

- Restored the compact Field notes landing and moved expanded Reading, Report and Dashboard compositions to a separate examples guide.
- Added example presets, a lean print view and an active example mode and surface indicator.

## 0.1.0-beta.2 (prepared, not released)

- Added Lead line and Thread patterns, including React bindings and HTML and React guidance.
- Expanded the showcase with reading, report and dashboard examples, plus component and principles reference pages.
- Preserved Panel grain and focal backgrounds in compositions, kept Thread geometry in print, and limited sticky Ledger headings to column headers.

## 0.1.0-beta.1 (prepared, not released)

- Prepared a free community beta as GitHub release files: core and React tarballs and a browser starter ZIP.
- Added Night and Day modes, Ledger and Folio surfaces, and experimental automatic Folio print styling.
- Prepared framework-neutral tokens and CSS, optional fonts and living light, structural React bindings and examples.
- Real Safari, manual assistive technology and physical monochrome print remain unobserved. See the [beta notes](docs/release/beta-release-notes.md).

No version has been published. These package names do not claim an npm namespace.
