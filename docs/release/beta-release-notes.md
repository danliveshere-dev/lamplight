# 0.1.0-beta.1 community beta notes

**Prepared locally, not released.** Lamplight is a free design system for calm interfaces, with framework-neutral CSS and optional React bindings.

The planned GitHub release contains `lamplight-core-0.1.0-beta.1.tgz`, `lamplight-react-0.1.0-beta.1.tgz` and `lamplight-browser-0.1.0-beta.1.zip`. Install tarballs from local files or serve the extracted browser starter. See the [adoption guide](../adoption.md). Package imports use `@lamplight/core` and `@lamplight/react`; packages remain private and no npm registry ownership or availability is claimed.

The beta includes Night and Day modes, Study, Ledger and Folio surfaces, opt-in IBM Plex font faces and optional living-light enhancement. It is a prerelease: documented contracts may change in response to feedback. Real Safari and manual assistive technology have not been observed. Folio print is experimental and physical monochrome print has not been observed. Consumers must check their own content and interactions.

Publication needs separate explicit acceptance and authority; see [readiness](beta-readiness.md).
