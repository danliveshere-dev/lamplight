A little light for useful things.

Lamplight is a small interface system for reading, working and sharing. It brings a calm, consistent character to the things people use.

Two modes describe the light: Night is lit against a dark ground; Day uses ink on a light ground. Three surfaces describe the work: Study gives reading room to breathe; Ledger helps people compare and work through information; Folio prepares content for print.

The examples use one fictional community garden project. All names, numbers and states are illustrative.

The Common Ground Project

Making room to grow.

A garden is never quite finished. At Common Ground, neighbours tend shared beds, care for the paths and make places to pause. Small observations help us decide what needs attention next.

Our fictional project keeps a simple record of each place, so volunteers can find a useful place to begin.

Bring Lamplight into your project

This beta is distributed as downloadable files. These examples assume you have downloaded and unpacked the release assets locally.

With a package manager

Install the core tarball from its local path. For React, also install the adapter tarball and React.

npm install ./lamplight-core-0.1.0-beta.2.tgz
npm install ./lamplight-react-0.1.0-beta.2.tgz react

Import @lamplight/core/styles.css and, if desired, @lamplight/core/fonts.css. React components are exported from @lamplight/react.

In a browser

Unpack the browser ZIP into your project, preserve its folders, and link the core stylesheet. Scope components with l-room.

<link rel="stylesheet" href="./core/lamplight.css">
<main class="l-room">...</main>

Fonts and living light are optional. Explore the component reference for markup and usage.
