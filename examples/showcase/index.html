A little light for useful things.

A bit of warmth for the things you read, work on and share. Have a look around, try the switches and see what fits your next project.

Two modes describe the light: Night is lit against a dark ground; Day uses ink on a light ground. Three surfaces describe the work: Study gives reading room to breathe; Ledger helps people compare and work through information; Folio prepares content for print.

We’ll use a fictional community garden to try things out. The people, numbers and states are all made up.

Bring Lamplight into your project

Pick the download that suits your project. It’s free, and you’re welcome to make it your own. Download and unpack the files before following the examples below.

Download core · Download React adapter · Download browser starter · SHA-256 checksums · Build manifest

With a package manager

Install the downloaded core tarball from its local path. Using React? Add the adapter tarball and React too.

npm install ./lamplight-core-0.1.0-beta.5.tgz
npm install ./lamplight-react-0.1.0-beta.5.tgz react

Import @lamplight/core/styles.css and, if desired, @lamplight/core/fonts.css. React components are exported from @lamplight/react.

In a browser

Unpack the browser ZIP into your project, preserve its folders, and link its core stylesheet from your page. Put l-document on the html element or scope components with l-room.

<link rel="stylesheet" href="./core/lamplight.css">
<main class="l-room">...</main>

The stylesheet includes tokens, components, modes and surfaces. Add fonts or living light if they suit what you’re making.

Build with AI
