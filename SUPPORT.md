# Support

Before the repository is public, there is no public support channel. After Gate
7, use a GitHub issue for reproducible defects and a discussion for adoption
questions if Discussions has been enabled.

Include the exact Lamplight version or commit, browser and framework versions,
a minimal synthetic reproduction, expected behaviour and observed behaviour.
Please do not include private application data, credentials or proprietary
consumer code.

Security concerns do not belong in a public issue. Follow `SECURITY.md`, which
will name the verified private reporting route after the public repository is
configured. Support is best-effort and has no guaranteed response or resolution
time.
