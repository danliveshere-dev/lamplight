# Support

Use [GitHub Issues](https://github.com/danliveshere-dev/lamplight/issues) for reproducible defects and documentation questions. Choose the closest issue template. GitHub Discussions is not enabled.

Support is best-effort. There is no guaranteed response or resolution time, but I'll do my best!

## Reporting a problem

Include the Lamplight version or commit, browser and framework versions, what you expected and what happened. Use a small example with invented data. If you have the download's SHA-256 checksum, include that too.

Keep private application data, credentials and proprietary code out of reports.

## Security concerns

Use [GitHub private vulnerability reporting](https://github.com/danliveshere-dev/lamplight/security/advisories/new) for undisclosed security concerns. The route is enabled and verified. See [the security policy](SECURITY.md) for what to report. Keep vulnerability details out of public issues.

## Community beta

The public beta is available as [GitHub release downloads](https://github.com/danliveshere-dev/lamplight/releases/tag/v0.1.0-beta.5). It has not been published to npm.

Beta feedback is most useful when it shows a reproducible installation, keyboard, rendering or documentation problem. Physical monochrome printing and manual assistive technology checks remain open. The [publication record](docs/release/beta-publication.md) lists the completed checks and remaining limits.
