# Support

Use [GitHub Issues](https://github.com/danliveshere-dev/lamplight/issues) for reproducible defects and documentation questions. Choose the closest issue template. GitHub Discussions is not enabled.

Include the exact Lamplight version or commit, browser and framework versions,
a minimal synthetic reproduction, expected behaviour and observed behaviour.
Please do not include private application data, credentials or proprietary
consumer code.

Report undisclosed security concerns through [GitHub private vulnerability reporting](https://github.com/danliveshere-dev/lamplight/security/advisories/new), as described in [the security policy](SECURITY.md). The route is enabled and verified. Keep vulnerability details out of public issues. Support is best-effort and has no guaranteed response or resolution
time.

## Community beta

The public beta is distributed as [GitHub release downloads](https://github.com/danliveshere-dev/lamplight/releases/tag/v0.1.0-beta.5), rather than npm registry packages. Give the exact archive version and, where available, its SHA-256
digest when reporting a problem. Beta feedback should focus on a reproducible
installation, keyboard, rendering or documentation issue with a small synthetic
example. Physical monochrome printing and manual assistive-technology coverage
are declared limitations, not completed acceptance tests.

The [publication record](docs/release/beta-publication.md) names the released source, hosted checks and remaining beta limits.
