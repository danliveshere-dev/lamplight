# Lamplight React beta

This package contains the React adapter. Download it from the [public beta release](https://github.com/danliveshere-dev/lamplight/releases/tag/v0.1.0-beta.5).

The package name is used for imports. It does not establish npm namespace ownership or registry availability. The manifest keeps `private: true` to prevent accidental npm publication; the download is public.

Install the downloaded `lamplight-react-0.1.0-beta.5.tgz` and `lamplight-core-0.1.0-beta.5.tgz` into a project with React 18 or newer, for example `npm install ./lamplight-core-0.1.0-beta.5.tgz ./lamplight-react-0.1.0-beta.5.tgz`. Import CSS from `@lamplight/core/styles.css` and components from `@lamplight/react`.
